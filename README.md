# Apache Kafka for Developer Using Spring Boot

This repository is for learning Kafka with Spring Boot, based on the [Kafka MicroServices with Spring Boot, Docker, Kubernetes, AI](https://www.udemy.com/course/apache-kafka-for-developers-using-springboot) course on Udemy.

The original course repository can be found here:\
[https://github.com/dilipsundarraj1/kafka-for-developers-using-spring-boot-v2](https://github.com/dilipsundarraj1/kafka-for-developers-using-spring-boot-v2)

## Prerequisites

- **JDK 25**
  - The project uses Java 25 via Gradle toolchain.
- **Docker & Docker Compose**
  - For running a local Kafka cluster (e.g., multiple brokers on `localhost:9092, 9093, 9094`).
- **HTTPie**
  - For sending HTTP requests to the Spring Boot application during development.
